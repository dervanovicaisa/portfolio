Case 03 / Fuel Me

Understand the existing behaviour before rebuilding it.

Migration of Customer Management functionality to a new design within an existing React application, using the codebase and scenario testing to understand behaviour where documentation was limited.

Role & team
Web developer / Trid Tech
Period
February 2022 – January 2023
Focus
Customer Management & design migration
01 / Context

The new design wasn't the whole story.

At Trid Tech, I contributed to migrating Customer Management functionality to a new design. The application was already built in React.

The existing application had limited documentation. Understanding how it worked required examining the codebase and testing different scenarios before rebuilding the functionality in the redesigned application.

02 / Contribution

Where I contributed.

  • Customer Management: contributed to the redesign of existing functionality.
  • Design migration: adapted existing Customer Management functionality to the new design within the React application.
  • Code investigation: used the existing codebase to understand behaviour where documentation was limited.
  • Scenario testing: tested different scenarios to understand current system behaviour before rebuilding it.
03 / Working process

Observe, test, then rebuild.

The existing application was a source of information about how Customer Management worked. I examined its code and tested scenarios to understand current behaviour.

That investigation informed my work on rebuilding the functionality in the redesigned application. The task connected understanding existing React functionality with adapting it to the new design.

Limited documentation made investigation part of the implementation process: the behaviour had to be understood before it could be rebuilt.
