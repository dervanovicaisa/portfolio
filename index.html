How I work
ALIGN ON THE PROBLEM

When a requirement is unclear, I ask what a feature needs to do and why, then work with the team to agree on expected behaviour before implementation.

MAKE THE SYSTEM VISIBLE

I use API documentation, existing code and live application tests to understand what the data means, which rules apply and how the parts depend on each other.

THINK BEYOND THE HAPPY PATH

Testing has revealed cases missing from the original requirements, including permission issues. I raise them with the team and help investigate issues during testing and after release.
